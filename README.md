# Happy Birthday Animation

A colorful, responsive "Happy Birthday" animation built with HTML, CSS and a bit of JavaScript.

![Preview of the animation](./Screenshot%202025-01-11%20233013.png)

## Description

This small project displays an animated birthday greeting using only front-end web technologies. It's designed to be easy to read, customize, and drop into any static site or demo page.

## Demo

To view the animation locally:

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Happy-Birthday-Animation-4.git

2. Open `index.html` in your browser (double-click the file or serve it with a static server).

That's it — the animation runs without any build steps or dependencies.

## Built With

- HTML
- CSS
- JavaScript

Language composition: HTML (~52%), JavaScript (~30%), CSS (~18%).

## Features

- Pure front-end animation — no build tools required
- Easy to customize text, colors and timing
- Lightweight and mobile-friendly

## File Structure

- `index.html` — main page containing the markup
- `style.css` — all styles and animations
- `script.js` — small JavaScript for interactive behavior
- `Screenshot 2025-01-11 233013.png` — preview screenshot used in this README

## Customize

- Change the message or add more elements in `index.html`.
- Tweak colors, fonts and animation timings in `style.css`.
- Modify or extend the interactivity in `script.js`.
